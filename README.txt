MATCH REPLAY v11

■ この差分の主な変更
- ブラウザ幅が 1920 未満のとき、横幅ぴったりで縮小
- 1920×1080 の外側は透明背景
- トップエリアを再設計
  - 名前を大会名と同じ行へ移動
  - SCORE 文字を削除
  - スコア表示を大型化
- 情報エリアを 3 分割
  - 左上: ジョーカー / アンチジョーカー
  - 右上: ムーブ・アクション履歴
  - 下: 候補手一覧
- 操作画面で編集可能
  - 大会名
  - 黒プレイヤー名
  - 白プレイヤー名
  - 黒白スコア
  - 棋譜ファイル選択
- /matches/ フォルダを追加
- stream-config.json へ表示設定を保存

■ Joker / Anti-Joker の仮基準
UI 上は「現局面からエクイティを大きく上下させる出目」を表示する設計です。
現状の叩きでは、代表的な上昇・下降ロールをサンプル表示しています。
