MATCH REPLAY v14

■ 変更内容
- サイコロイラストを高品質化
  - Unicode記号ではなく、CSSで描画する大きめのダイスへ変更
  - 履歴エリアとジョーカー / アンチジョーカー表示の両方に適用
- 大会名エリアを2行化
  - 1行目: 大きく表示
  - 2行目: 小さく表示
  - どちらも中央揃え
- 操作画面から以下を編集可能に変更
  - 大会名1行目
  - 大会名2行目
  - 黒白プレイヤー名
  - 黒白スコア
  - 棋譜ファイル
- stream-config.json を2行タイトル構成へ更新

例:
1行目: JBS第31期名人戦 準々決勝
2行目: 2025/08/30　25ポイントマッチ　勝てばベスト4
