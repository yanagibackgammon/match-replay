MATCH REPLAY v23

■ 変更内容
- 再生モードを「自動」「手動」の2モード化
- 自動モードは1秒ごとに進行
- チェッカープレーを以下の4段階表示に分割
  1. ジョーカー表示
  2. ロール
  3. 解析結果表示
  4. ムーブ
- 手動モードは「前へ」「次へ」で上記表示を1段階ずつ操作
- ゲーム開始時、盤面中央に「Game N」を表示
- 手番プレイヤーの履歴欄の名前下に赤線を表示
- 勝率バーの数字を白文字＋黒輪郭＋影付きに変更
- 再生間隔を1000msに固定

※ xg-parser.cjs を更新しているため、GitHub PagesではDeploy GitHub Pages実行時に
   matches/generated の配信用JSONが新しい4段階形式で再生成されます。
※ ローカルでは server.js 再起動後、棋譜選択時に新形式で再解析されます。
